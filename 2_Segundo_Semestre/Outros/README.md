## 🎲 Calculadora de Análise Combinatória

* **Arquivo**: [`calculadora_combinatoria.c`](./calculadora_combinatoria.c)
* **Linguagem**: C

### 📋 Funcionalidades
Programa interativo em linha de comando que implementa os principais cálculos de matemática discreta e combinatória:
1. **Permutações Simples**: \(P_n = n!\)
2. **Permutações com Elementos Repetidos**: \(P_n^{n_1, n_2, \dots, n_k} = \frac{n!}{n_1! \cdot n_2! \dots n_k!}\)
3. **Arranjos Simples**: \(A(n, k) = \frac{n!}{(n - k)!}\)
4. **Combinações Simples**: \(C(n, k) = \binom{n}{k} = \frac{n!}{k!(n - k)!}\)
5. **Combinações com Repetição**: \(CR(n, k) = \binom{n + k - 1}{k}\)
